The manifest minimum is Android 13; this is not a list of supported devices. A manufacturer or Android update can change privileged audio behavior. Do not treat a successful build or ready label as proof of call audio.

Submit your result using the Android compatibility issue template. Include the precise APK version, phone model and Android version. No phone number, serial number, contact name or recording is needed. Maintainers will distinguish a community report from an independently reproduced result when updating this table.
