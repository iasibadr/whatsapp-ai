# Installation et utilisation

## Préparation

- Téléphone Android 13 ou supérieur selon le manifeste ; référence observée : Pixel 8 Pro sous Android 17. Ce minimum technique n'est pas une validation de tous les appareils.
- Architecture ARM64, WhatsApp classique installé et connecté à votre compte.
- Accès Internet, compte API OpenAI personnel et budget d'utilisation propre. L'abonnement ChatGPT n'est pas une clé API.
- Autorisation d'installer votre APK depuis la source choisie. Vérifier son SHA-256 avant installation.

## Configuration

1. Installer l'APK hors appel. Une mise à jour Android exige le même identifiant de paquet et un certificat compatible ; une compilation personnelle n'est pas nécessairement compatible avec l'APK fournie.
2. Ouvrir les réglages de l'application et configurer votre propre clé. Ne pas la transmettre dans un ticket, une capture ou un modèle de mission.
3. Autoriser les seules permissions nécessaires et lire les explications affichées.
4. Activer les options développeur et le débogage sans fil Android pour l'association locale. Saisir le code uniquement dans le parcours d'association de votre téléphone ; aucun code n'est fourni par ce dépôt.
5. Activer le relais hors appel. Attendre l'état prêt et consulter le diagnostic si nécessaire. Après redémarrage, vérifier à nouveau ; la reprise automatique n'est pas validée.
6. Préparer une mission courte, informer le correspondant de la présence d'une IA et confirmer un seul appel. Garder la possibilité de reprendre ou terminer la conversation.

Un appel lancé directement depuis WhatsApp ne déclenche pas automatiquement l’IA. Si le relais s’arrête, votre microphone peut être entendu : consulter l’état et reprendre ou terminer l’appel dans WhatsApp.

## Partager

Choisir « Partager l’APK seule ». Les clés, associations, contacts et historiques ne doivent jamais accompagner la distribution. Relire séparément tout modèle de mission exporté : il peut contenir les informations de son auteur.

## En cas d'échec

Ne pas désactiver les contrôles de propriétaire audio ou d'identité d'appel. Arrêter l'essai et reprendre manuellement. Pour un rapport, indiquer version de l'application, modèle du téléphone, Android et étapes synthétiques ; retirer les données personnelles des captures et diagnostics.
