# Roadmap and contribution priorities

## Available

Original signed preview APK, source build, policy checks, installation guide, privacy review and issue templates. The APK is not a production security certification.

## Needed before broader confidence

1. Collect consented end-to-end audio reports across Android manufacturers and versions.
2. Test manual takeover, hangup and failures without automatically redialing.
3. Test restart and full-reboot behavior independently of the ready indicator.
4. Review privileged boundaries and permissions; retain fail-closed checks.
5. Resolve the 21 reported lint errors and assess the 86 warnings without blanket suppression. Update the stale internal version string in a new source/APK version.
6. Publish an evidence-backed compatibility matrix; unknown devices remain unknown.

No dates or universal compatibility promises are attached to this roadmap. An iOS port, cloud service, unrelated automation and covert calling are outside this release.
