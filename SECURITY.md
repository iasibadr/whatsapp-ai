# Security

This project uses privileged Android audio behavior and is experimental. It has not received an independent security audit. Do not treat compilation, an APK signature, a ready indicator or a pattern scan as a security guarantee.

Do not post vulnerabilities containing secrets or personal data in public issues. Use GitHub private vulnerability reporting if enabled for this repository. If it is unavailable, open a minimal issue requesting a private contact channel without exploit details or private logs.

Do not submit API keys, pairing codes, signing keys, call content or device dumps. Keep only necessary redacted reproduction steps. Verify APK hashes and use your own model credentials. Never weaken call-owner, UID or permission checks to bypass an unsupported-device failure.
