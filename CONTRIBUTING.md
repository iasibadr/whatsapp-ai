# Contributing

Use a branch and a pull request. Describe the problem, expected behavior, exact app and Android versions, and the smallest synthetic reproduction. Run the documented build/tests and publication scan. Separate software checks from a real-device observation.

No personal contacts, credentials, raw recordings, production logs or private infrastructure addresses belong in a contribution. Keep safety checks, participant awareness and manual takeover. Changes to privileges or data retention need explicit documentation and tests.

Contributions to original application code are submitted under the MIT license. Preserve third-party notices. Do not claim compatibility or audio success without a documented consented test.
