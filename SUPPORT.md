# Support and testing

This project is a community preview maintained by Charadi Badr, not a supported commercial calling service. Response times and fixes are not guaranteed.

- [Report an Android compatibility test](https://github.com/iasibadr/whatsapp-ai/issues/new?template=android_compatibility.md)
- [Report a reproducible bug](https://github.com/iasibadr/whatsapp-ai/issues/new?template=bug_report.md)
- [Read installation instructions](docs/INSTALLATION.md)
- [Review security reporting](SECURITY.md)

Report the app version, phone model, Android version and observed behavior. Explicitly distinguish installation, relay startup, hearing both sides of a real consented call, manual takeover and restart recovery. A ready indicator is not an audio test.

Never include a real phone number, contact name, account identifier, API key, pairing code, call recording or raw diagnostic dump. Do not post a vulnerability with sensitive details in an ordinary public issue.

Français : les retours positifs comme négatifs sur différentes marques Android sont bienvenus. Utilisez le formulaire de compatibilité ; aucun accès à votre compte ou à votre téléphone ne sera demandé dans un ticket public.
